# 双色球随机号码生成工具

## 项目简介
本项目是一个用于生成中国福利彩票双色球随机号码的工具。用户可以自定义生成的注数，工具将根据双色球的规则随机生成红球和蓝球号码。

## 文件结构
```
ssq-generator
├── src
│   ├── generate.js        // 随机号码生成的主要逻辑
│   └── utils.js           // 辅助函数
├── package.json           // npm配置文件
├── .gitignore             // 版本控制忽略文件
└── README.md              // 项目文档
```

## 使用说明

### 安装依赖
在项目根目录下，运行以下命令以安装所需的依赖：
```
npm install
```

### 生成号码
要生成双色球号码，请在 `src/generate.js` 文件中调用 `generateSSQ` 函数，并传入希望生成的注数。例如：
```javascript
generateSSQ(5); // 生成5注号码
```

### 修改生成注数
在调用 `generateSSQ` 函数时，可以根据需要修改参数 `count` 来生成不同数量的注数。默认情况下，生成1注号码。

### 执行代码
可以通过 Node.js 运行 `generate.js` 文件来执行号码生成：
```
node src/generate.js
```
