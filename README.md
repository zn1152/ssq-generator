# 双色球随机号码生成工具

## 项目简介
这是一个基于网页的中国福利彩票双色球随机号码生成工具。支持普通投注、复式投注和胆拖投注三种玩法，可以根据需要自定义各类参数。

## 功能特点
- 支持三种投注方式：
  - 普通投注：随机生成指定注数的标准号码
  - 复式投注：可选择更多红球和蓝球组合
  - 胆拖投注：支持设置胆码，自动生成或手动输入拖码
- 自动计算注数和投注金额
- 直观的号码展示界面
- 响应式设计，支持手机访问

## 使用说明

### 普通投注
1. 选择"普通投注"标签
2. 输入需要生成的注数
3. 点击"生成号码"按钮

### 复式投注
1. 选择"复式投注"标签
2. 设置以下参数：
   - 注数：要生成的复式组合数量
   - 红球个数：选择6-33个红球
   - 蓝球个数：选择1-16个蓝球
3. 点击"生成号码"按钮

### 胆拖投注
1. 选择"胆拖投注"标签
2. 输入胆码（1-5个，用逗号分隔）
3. 可选：输入拖码（若不输入则自动随机生成）
4. 设置蓝球个数（1-16个）
5. 点击"生成号码"按钮

## 本地运行
1. 下载项目文件
2. 直接在浏览器中打开 index.html 文件
3. 或使用本地服务器运行（如 VS Code 的 Live Server 插件）

## 技术说明
- 纯前端实现，无需后端服务
- 使用 Fisher-Yates 算法确保随机性
- 自动计算组合数，显示注数和金额
